# 8K Labels — Traditional / Heritage label engine

A self-contained SVG wine-label generator. From the wine's text fields and a
label size it produces print-ready front-label options across three families
(no-image / small-image / large-image), each reproducing a set of fixed
compositions extracted from the client's reference PDFs. Only the typography,
background tone and frame vary between generations; the layouts themselves are
fixed and print-correct (real physical size, 2 mm bleed, 5 mm safety margin).

The engine renders **inline SVG** — no server, no canvas rasterisation. Every
option can be downloaded as a real `.svg` at the exact physical size.

│   ├── configurator.html    ← the full client configurator (open this)
│   └── prototype.html       ← standalone engine playground

├── design-references/       ← the client PDFs the compositions were traced from
├── tests/

    ├── ARCHITECTURE.md      ← how the engine is structured and renders
    ├── HANDOFF.md           ← developer setup, known limitations, next steps

**If you only keep three files**, keep `src/label-engine.js` (the engine),
`src/img-data.js` (the placeholder image) and `dist/configurator.html` (the
built product). Everything else can be rebuilt from those plus the base page.

## Quick start

Open `dist/configurator.html` in a browser — it's fully self-contained (engine,
image and editor are inlined). Fill in the fields, set the size, and click the
front-label preview / **Other options** to generate.

### Rebuilding after you edit the source

```bash
node build.js        # reads src/*, writes dist/configurator.html + dist/prototype.html
```

`build.js` uses only Node's standard library — no `npm install` needed to build.

### Running the verifier (optional but recommended after engine edits)

```bash
npm i -D playwright   # once; provides a headless Chromium
node tests/verify.js  # renders 144 label variants and checks margins/overlaps/bleed
```

A green run prints `ALL CLEAN`. Any margin breach, text overlap, or wrong
artboard/bleed is listed with the exact size + seed + option.

## Fonts (important)

The label typography uses Google Fonts, pulled in by an `@import` inside each
SVG (`FONTS_URL` at the top of `label-engine.js`) and also injected page-side by
`ensureFonts()`. **The fonts load from `fonts.googleapis.com`** — so the browser
opening the configurator needs network access for the type to render as
designed (blackletter is intentionally excluded; the no-image family uses
calligraphic scripts, the image families use traditional serifs). If fonts are
blocked, everything still lays out correctly but falls back to a system serif.

To self-host the fonts instead (recommended for production/offline), see
`docs/HOW-TO-EDIT.md → "Self-hosting the fonts"`.

## Physical output

* Artboard = the **real trim size** you enter (e.g. `100 mm × 80 mm`). The SVG
  carries `width`/`height` in millimetres and a matching `viewBox`.
* The **background and image bleed 2 mm** beyond the artboard on every side.
* No text ever crosses the **5 mm safety margin**.
* One internal unit = **0.1 mm** (so a 100 mm width is 1000 units).

See `docs/RULES.md` for the complete, authoritative list of design rules.
